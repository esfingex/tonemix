About

ToneMix is a professional-grade music library manager designed to bridge the gap between production and performance. It offers robust metadata handling, precise key/BPM detection, and high-quality transcoding for CDJ workflows.

✨ Key Features

🎹 Analysis

Camelot Key detection (1A-12B), precise BPM analysis, and Energy Level rating (0-10). Dual-deck colored waveform visualization.

🖼️ Library

High-res album artwork (90px), database-backed search, smart "All Tracks" view, and drag & drop import.

🔄 Transcoding

Convert FLAC/WAV to AIFF/MP3 seamlessly. Lossless Metadata Preservation ensures all your tags and artwork arrive intact on your USBs.

🎮 Control

Fully configurable keyboard shortcuts, playlists management, and Rekordbox XML export.

🚀 Quick Start

To install and run ToneMix on Linux or macOS:

git clone https://github.com/esfingex/tonemix.git
cd tonemix
./setup.sh
./run.sh
