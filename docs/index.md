# ToneMix Documentation

Welcome to the technical documentation for **ToneMix**, the advanced DJ library management tool.

## Overview

ToneMix is a Python-based application designed to bridge the gap between various DJ software and library formats. It offers a modern, dark-themed UI built with PySide6.

## Key Features

- **Library Management**: scan and organize your local music collection.
- **Playlist Management**: Create, rename, and delete playlists.
- **Audio Transcoding**: Convert tracks between formats (AIFF, WAV, MP3, FLAC) preserving tags.
- **Device Integration**: Seamlessly read from USB drives.

## 🔌 Rekordbox Integration (New!)

ToneMix now features a native, high-performance integration with Rekordbox formatted USB drives.

### PDB Import Features

1. **Direct PDB Parsing**: Reads the binary `export.pdb` (DeviceSQL) file directly from the USB, bypassing the need for XML exports.
2. **Universal Compatibility**:
    - Implements a **Dynamic Heuristic Scanner** that automatically identifies internal database tables by analyzing their content.
    - Works with any Rekordbox version, ignoring hardcoded Type IDs that may change.
3. **High Performance**:
    - Uses **Memory Mapping (`mmap`)** for instant read access, even on large databases.
    - Zero external dependencies (no C++ compilers required).

### How to Use

1. Connect your Rekordbox USB drive.
2. Open the **DEVICES** section in the ToneMix sidebar.
3. Click on your device (e.g., `IVIR_R1`).
4. Browse your folders and playlists instantly.

## Architecture

ToneMix conforms to a clean, modular architecture:

- **`src.ui`**: PySide6 widgets and main window logic.
- **`src.database`**: SQLRepository pattern for data persistence.
- **`src.importer`**: specialized modules for parsing formats (Rekordbox PDB, XML, Serato).
- **`src.audio`**: FFMpeg wrappers for transcoding.
